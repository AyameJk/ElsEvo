Política de Privacidade

Última atualização: agosto de 2026

✓

Resumindo: o ElsEvo não coleta, armazena ou compartilha nenhum dado pessoal seu. Nem o site, nem o aplicativo. Tudo o que o programa salva fica apenas no seu próprio computador.

01 Sobre este documento

Esta política se aplica ao site ayamejk.github.io/ElsEvo e ao aplicativo ElsEvo (canais Estável e Beta), um gerenciador de mods gratuito e de código aberto para o jogo Elsword, desenvolvido de forma independente por um único desenvolvedor (AyameJk).

02 O site

O site é uma página estática hospedada no GitHub Pages. Ele não possui formulários, sistema de cadastro, cookies de rastreamento, pixels de anúncio ou qualquer script de análise de comportamento (analytics). As únicas preferências salvas no seu navegador (tema claro/escuro e idioma escolhido) ficam guardadas localmente via localStorage, no seu próprio dispositivo — nunca são enviadas a nenhum servidor.

03 O aplicativo

O ElsEvo roda localmente no seu computador e não envia dados pessoais para nenhum servidor. As únicas conexões de rede que o app faz são:

  • Verificar se existe uma nova versão disponível, consultando um arquivo público de metadados no GitHub (sem enviar nenhuma informação sobre você ou sua máquina);
  • Baixar o instalador de atualização diretamente do GitHub Releases, quando você autoriza a atualização.

Configurações do app (idioma, tema, caminho da pasta do jogo) e a lista de mods ativos ficam salvas apenas localmente, na pasta %LocalAppData%\ElsEvo\ do seu próprio computador. Nada disso é enviado para fora da sua máquina.

04 Dados de terceiros

O download do instalador é servido pela infraestrutura do GitHub (GitHub Releases), que pode registrar dados técnicos padrão de acesso (como endereço IP), conforme a própria política de privacidade do GitHub — o ElsEvo não tem acesso a esses dados e não os utiliza.

05 Doações (Pix / PayPal)

A seção de apoio ao projeto apenas exibe uma chave Pix e um link para o PayPal. Nenhuma transação é processada pelo site — ao doar, você é redirecionado para o aplicativo do seu banco ou para o site oficial do PayPal, que têm suas próprias políticas de privacidade.

06 Alterações nesta política

Caso esta política seja atualizada no futuro, a data no topo desta página será revisada. Como o projeto não coleta contatos dos usuários, não há como notificar individualmente — recomenda-se revisitar esta página periodicamente.
